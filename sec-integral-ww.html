    Subsection Section 4.1 Antiderivatives

    Example 4.7.1.

    Find the most general antiderivative of
    \begin{equation*} f(x) = 4x^2 - \frac{1}{x^3} + \sin(2x). \end{equation*}
    Check your answer by differentiating.
    🔗
    Solution.
    First rewrite the function using exponents:
    🔗
    \begin{equation*} f(x) = 4x^2 - x^{-3} + \sin(2x). \end{equation*}
    Now use the rules for antiderivatives 4.1.6 of powers and trigonometric functions, along with linearity, to build an antiderivative term-by-term:
    🔗
    \begin{equation*} F(x) = 4\left(\frac{1}{3}x^3\right) + \frac{1}{2}x^{-2} - \frac{1}{2}\cos(2x) + C \end{equation*}
    We can check our answer by differentiating:
    🔗
    \begin{equation*} \begin{aligned} \amp \; \frac{d}{dx}\left(\frac{4x^3}{3} + \frac{1}{2}x^{-2} - \frac{1}{2}\cos(2x) + C\right)\\[6pt] \amp= \frac{4}{3}\cdot 3x^2 + \frac{1}{2}(-2)x^{-3} - \frac{1}{2}(-\sin(2x))\cdot 2 \\[6pt] \amp= 4x^2 - x^{-3} + \sin(2x) \\[6pt] \amp= 4x^2 - \frac{1}{x^3} + \sin(2x) \end{aligned} \end{equation*}
    Since differentiating recovers the original function, the result is confirmed as the most general antiderivative.
    🔗
    🔗
    🔗

    Example 4.7.2.

    Find the antiderivative \(F(x)\) of
    \begin{equation*} f(x) = \frac{2}{x^4} - \frac{9}{2x^2} \end{equation*}
    which satisfies \(F(-1)=10\text{.}\)
    🔗
    Solution.
    First rewrite the function using exponents:
    🔗
    \begin{equation*} f(x) = 2x^{-4} - \frac{9}{2}x^{-2}. \end{equation*}
    Now use the rules for antiderivatives 4.1.6 of powers, along with linearity, to build the most general antiderivative term-by-term:
    🔗
    \begin{equation*} F(x) = 2\left(\frac{x^{-3}}{-3}\right) - \frac{9}{2}\left(\frac{x^{-1}}{-1}\right) + C \end{equation*}
    Simplifying gives
    🔗
    \begin{equation*} F(x) = -\frac{2}{3}x^{-3} + \frac{9}{2}x^{-1} + C. \end{equation*}
    Since \(F(-1)=10\text{,}\) substitute \(x=-1\) to find \(C\text{:}\)
    🔗
    \begin{equation*} \begin{aligned} 10 \amp= F(-1) \\[4pt] \amp= -\frac{2}{3}(-1)^{-3} + \frac{9}{2}(-1)^{-1} + C \\[4pt] \amp= \frac{2}{3} - \frac{9}{2} + C. \end{aligned} \end{equation*}
    Solving for \(C\text{,}\) we get
    🔗
    \begin{equation*} \begin{aligned} C \amp= 10 - \frac{2}{3} + \frac{9}{2} \\[4pt] \amp= \frac{60}{6} - \frac{4}{6} + \frac{27}{6} \\[4pt] \amp= \frac{83}{6}. \end{aligned} \end{equation*}
    Therefore, the antiderivative is
    🔗
    \begin{equation*} F(x) = -\frac{2}{3}x^{-3} + \frac{9}{2}x^{-1} + \frac{83}{6}. \end{equation*}
    We can check our answer by differentiating and verifying the given value:
    🔗
    \begin{equation*} \begin{aligned} F'(x) \amp= \frac{d}{dx}\left(-\frac{2}{3}x^{-3} + \frac{9}{2}x^{-1} + \frac{83}{6}\right) \\[4pt] \amp= -\frac{2}{3}(-3)x^{-4} + \frac{9}{2}(-1)x^{-2} \\[4pt] \amp= 2x^{-4} - \frac{9}{2}x^{-2} \\[4pt] \amp= \frac{2}{x^4} - \frac{9}{2x^2} \end{aligned} \end{equation*}
    \begin{equation*} \begin{aligned} F(-1) \amp= -\frac{2}{3}(-1)^{-3} + \frac{9}{2}(-1)^{-1} + \frac{83}{6} \\[4pt] \amp= \frac{2}{3} - \frac{9}{2} + \frac{83}{6} \\[4pt] \amp= 10. \end{aligned} \end{equation*}
    Since \(F'(x)=f(x)\) and \(F(-1)=10\text{,}\) the result is confirmed.
    🔗
    🔗
    🔗

    Example 4.7.3.

    Find the most general antiderivative of
    \begin{equation*} f(x) = \frac{3\sqrt{x}-2x^3}{x}. \end{equation*}
    Check your answer by differentiating.
    🔗
    Solution.
    First simplify the expression and rewrite using exponents:
    🔗
    \begin{equation*} f(x) = \frac{3\sqrt{x}}{x} - \frac{2x^3}{x} = 3x^{-1/2} - 2x^2. \end{equation*}
    Now use the rules for antiderivatives 4.1.6 of powers, along with linearity, to build an antiderivative term-by-term:
    🔗
    \begin{equation*} F(x) = 3\left(\frac{x^{1/2}}{1/2}\right) - 2\left(\frac{x^3}{3}\right) + C \end{equation*}
    Simplifying gives
    🔗
    \begin{equation*} F(x) = 6x^{1/2} - \frac{2}{3}x^3 + C. \end{equation*}
    We can check our answer by differentiating:
    🔗
    \begin{equation*} \begin{aligned} \amp \; \frac{d}{dx}\left(6x^{1/2} - \frac{2}{3}x^3 + C\right) \\[6pt] \amp= 6\left(\frac{1}{2}x^{-1/2}\right) - \frac{2}{3}(3x^2) \\[6pt] \amp= 3x^{-1/2} - 2x^2. \end{aligned} \end{equation*}
    Since differentiating recovers the original function, the result is confirmed as the most general antiderivative.
    🔗
    🔗
    🔗

    Example 4.7.4.

    An object moves along a coordinate line with velocity
    \begin{equation*} v(t) = 6t^2 - 7 \end{equation*}
    (in units per second). Its initial position is 5 units to the left of the origin. Find the position of the object after 3 seconds.
    🔗
    Solution.
    Let \(s(t)\) be the position of the object at time \(t\text{.}\) Since velocity is the derivative of position, we have
    🔗
    \begin{equation*} s'(t) = v(t) = 6t^2 - 7. \end{equation*}
    Thus \(s(t)\) is an antiderivative of \(6t^2 - 7\text{.}\) Using the rules for antiderivatives 4.1.6, we obtain the most general form:
    🔗
    \begin{equation*} s(t) = 2t^3 - 7t + C. \end{equation*}
    We are given that the initial position is 5 units to the left of the origin, so \(s(0) = -5\text{.}\) Substituting:
    🔗
    \begin{equation*} \begin{aligned} s(0) -5 \amp= 2(0)^3 - 7(0) + C \\[4pt] -5 \amp= C. \end{aligned} \end{equation*}
    Therefore \(C = -5\text{,}\) and the position function is
    🔗
    \begin{equation*} s(t) = 2t^3 - 7t - 5. \end{equation*}
    To find the position after 3 seconds, evaluate:
    🔗
    \begin{equation*} \begin{aligned} s(3) \amp= 2(3)^3 - 7(3) - 5 \\[4pt] \amp= 54 - 21 - 5 \\[4pt] \amp= 28. \end{aligned} \end{equation*}
    Since the position is positive, the object is 28 units to the right of the origin after 3 seconds.
    🔗
    We can check our work by differentiating:
    🔗
    \begin{equation*} \begin{aligned} s'(t) \amp= \frac{d}{dt}\left(2t^3 - 7t - 5\right) \\[4pt] \amp= 6t^2 - 7 \\[4pt] \amp= v(t). \end{aligned} \end{equation*}
    Since differentiating recovers the given velocity, the result is confirmed.
    🔗
    🔗

    Example 4.7.5.

    Solve the initial value problem:
    \begin{equation*} \frac{dy}{dt} = \frac{2}{t^2+1} - \frac{9}{2t}, \quad y(-1)=0. \end{equation*}
    🔗
    Solution.
    Our goal is to find a function \(y(t)\) such that \(y' = \frac{2}{t^2+1} - \frac{9}{2t}\) and \(y(-1)=0\text{.}\)
    🔗
    First, we find the most general antiderivative of the right-hand side by using the rules for antiderivatives 4.1.6.
    🔗
    \begin{equation*} y(t) = 2\arctan(t) - \frac{9}{2}\ln|t| + C. \end{equation*}
    Now we use the initial condition \(y(-1)=0\) to solve for \(C\text{:}\)
    🔗
    \begin{equation*} \begin{aligned} 0 \amp= y(-1) \\[4pt] 0\amp= 2\arctan(-1) - \frac{9}{2}\ln|-1| + C \\[4pt] 0\amp= 2\left(-\frac{\pi}{4}\right) - 0 + C \\[4pt] 0\amp= -\frac{\pi}{2} + C \\[4pt] \frac{\pi}{2} \amp = C \end{aligned} \end{equation*}
    Therefore, the solution to the initial value problem is
    🔗
    \begin{equation*} y(t) = 2\arctan(t) - \frac{9}{2}\ln|t| + \frac{\pi}{2}. \end{equation*}

    Example 4.7.6.

    A small population is decreasing over time. Let \(P(t)\) be the population after \(t\) years. Suppose the rate of change is modeled by
    \begin{equation*} P'(t) = -15e^{-0.2t}. \end{equation*}
    🔗
    1. Write a general formula for \(P(t)\) assuming an unknown initial population.
      🔗
      🔗
    2. If the initial population is \(500\text{,}\) find the specific formula for \(P(t)\text{.}\)
      🔗
      🔗
    3. According to the model, what will the population be after 3 years?
      🔗
      🔗
    Solution.
    (a) Since \(P'(t)\) is given, the function \(P(t)\) is an antiderivative of \(-15e^{-0.2t}\text{.}\)
    🔗
    Using the rules for antiderivatives 4.1.6, we obtain:
    🔗
    \begin{equation*} P(t) = -15\left(\frac{1}{-0.2}e^{-0.2t}\right) + C. \end{equation*}
    Simplifying gives
    🔗
    \begin{equation*} P(t) = 75e^{-0.2t} + C. \end{equation*}
    This is the general formula.
    🔗
    (b) Now use the initial condition \(P(0)=500\text{:}\)
    🔗
    \begin{equation*} \begin{aligned} 500 \amp= P(0) \\[4pt] 500 \amp= 75e^{0} + C \\[4pt] 500 \amp= 75 + C\\[4pt] 425 \amp= C \end{aligned} \end{equation*}
    Therefore, the specific formula is
    🔗
    \begin{equation*} P(t) = 75e^{-0.2t} + 425. \end{equation*}
    (c) Now evaluate at \(t=3\text{:}\)
    🔗
    \begin{equation*} P(3) = 75e^{-0.6} + 425 \end{equation*}
    With access to a calculator (if one is permitted), we can find a decimal approximation to be about \(466\text{.}\)

    Example 4.7.7. Comparing Left, Right, Upper, and Lower Sums.

    Estimate the area under the graph of \(f(x)=5-x^2\) on the interval \([-2,1]\) using \(n=3\) rectangles of equal width.
    🔗
    Compute:
    🔗
    1. the left Riemann sum
      🔗
    2. the right Riemann sum
      🔗
    3. an overestimate (upper sum)
      🔗
    4. an underestimate (lower sum)
      🔗
    Solution.
    First compute the width of each rectangle:
    🔗
    \begin{equation*} \displaystyle \Delta x=\frac{1-(-2)}{3}=1. \end{equation*}
    The partition points are:
    🔗
    \begin{equation*} -2,\;-1,\;0,\;1. \end{equation*}
    The subintervals are:
    🔗
    \begin{equation*} [-2,-1],\quad [-1,0],\quad [0,1]. \end{equation*}
    (a) Left Riemann Sum
    🔗
    \begin{equation*} \begin{aligned} f(-2)\amp=1,\\ f(-1)\amp=4,\\ f(0)\amp=5 \end{aligned} \end{equation*}
    \begin{equation*} \displaystyle \text{Left Riemann Sum } =(1+4+5)(1)=10. \end{equation*}
    Graphically, the left sum corresponds to rectangles that touch the curve at the left endpoints of the subintervals.
    🔗
    (b) Right Riemann Sum
    🔗
    \begin{equation*} \begin{aligned} f(-1)\amp=4,\\ f(0)\amp=5,\\ f(1)\amp=4 \end{aligned} \end{equation*}
    \begin{equation*} \displaystyle \text{Right Riemann Sum }=(4+5+4)(1)=13. \end{equation*}
    Graphically, the right sum corresponds to rectangles that touch the curve at the right endpoints of the subintervals.
    🔗
    (c) Upper Sum (Overestimate)
    🔗
    To determine upper and lower sums, note that \(f(x)=5-x^2\) is increasing on \([-2,0]\) and decreasing on \([0,1]\text{.}\)
    🔗
    Use the maximum value on each subinterval:
    🔗
    \begin{equation*} \begin{aligned} f(-1)\amp=4,\\ f(0)\amp=5,\\ f(0)\amp=5 \end{aligned} \end{equation*}
    \begin{equation*} \displaystyle \text{Upper Sum }=(4+5+5)(1)=14. \end{equation*}
    (d) Lower Sum (Underestimate)
    🔗
    Use the minimum value on each subinterval:
    🔗
    \begin{equation*} \begin{aligned} f(-2)\amp=1,\\ f(-1)\amp=4,\\ f(1)\amp =4 \end{aligned} \end{equation*}
    \begin{equation*} \displaystyle \text{Lower Sum }=(1+4+4)(1)=9. \end{equation*}
    So we have:
    🔗
    \begin{equation*} \displaystyle \text{Lower Sum}=9 \le \text{Actual Area} \le 14=\text{Upper Sum}. \end{equation*}
    The left and right sums, \(10\) and \(13\text{,}\) fall between these bounds.
    🔗
    🔗
    🔗

    Example 4.7.8. Estimating Distance from a Velocity Table.

    The following table gives the velocity \(v(t)\) (in ft/s) of a particle moving along a horizontal axis at different times \(t\) (in seconds).
    🔗
    \begin{equation*} \begin{array}{c|ccccc} t & 20 & 23 & 26 & 29 & 32 \\ \hline v(t) & 15 & 10 & 7 & 9 & 12 \end{array} \end{equation*}
    Estimate the distance traveled by the particle from \(t=20\) to \(t=32\) using 4 subintervals of equal width.
    🔗
    1. Use left endpoints.
      🔗
    2. Use right endpoints.
      🔗
    3. Find an overestimate of the distance assuming all minimums and maximums are at the endpoints.
      🔗
    Solution.
    First compute the width of each subinterval:
    🔗
    \begin{equation*} \displaystyle \Delta t = \frac{32-20}{4} = 3. \end{equation*}
    (a) Left Endpoint Approximation
    🔗
    The left endpoints are:
    🔗
    \begin{equation*} 20,\;23,\;26,\;29. \end{equation*}
    So the estimated distance is:
    🔗
    \begin{equation*} \begin{aligned} \text{Distance} &\approx 3\bigl[v(20)+v(23)+v(26)+v(29)\bigr] \\ &= 3(15+10+7+9) \\ &= 3(41) = 123 \text{ ft}. \end{aligned} \end{equation*}
    (b) Right Endpoint Approximation
    🔗
    The right endpoints are:
    🔗
    \begin{equation*} 23,\;26,\;29,\;32. \end{equation*}
    So the estimated distance is:
    🔗
    \begin{equation*} \begin{aligned} \text{Distance} &\approx 3\bigl[v(23)+v(26)+v(29)+v(32)\bigr] \\ &= 3(10+7+9+12) \\ &= 3(38) = 114 \text{ ft}. \end{aligned} \end{equation*}
    (c) Overestimate
    🔗
    To find an overestimate, take the maximum velocity on each subinterval. Because we are told that all minimums and maximums are at the endpoints, we only need to look at the values in the table:
    🔗
    \begin{equation*} \begin{array}{c|cccc} \text{Interval} & [20,23] & [23,26] & [26,29] & [29,32] \\ \hline \text{Max } v(t) & 15 & 10 & 9 & 12 \end{array} \end{equation*}
    So the overestimate is:
    🔗
    \begin{equation*} \begin{aligned} \text{Distance} &\approx 3(15+10+9+12) \\ &= 3(46) = 138 \text{ ft}. \end{aligned} \end{equation*}

    Subsection Section 4.4 The Fundamental Theorem of Calculus

    Example 4.7.11.

    Evaluate the definite integral:
    🔗
    \begin{equation*} \displaystyle \int_{-1}^{3} 2(x+1)^2\,dx \end{equation*}
    Solution.
    First expand the integrand:
    🔗
    \begin{equation*} 2(x+1)^2 = 2(x^2+2x+1) = 2x^2+4x+2. \end{equation*}
    Now apply the Fundamental Theorem of Calculus:
    🔗
    \begin{equation*} \begin{aligned} \displaystyle \int_{-1}^{3} 2(x+1)^2\,dx &= \displaystyle \int_{-1}^{3} (2x^2+4x+2)\,dx \\ &= \left[\frac{2x^3}{3} + \frac{4x^2}{2} + 2x \right]_{-1}^{3}. \end{aligned} \end{equation*}
    Evaluate at the bounds:
    🔗
    \begin{equation*} \begin{aligned} &= \left( \frac{2(3)^3}{3} + 2(3)^2 + 2(3) \right) - \left( \frac{2(-1)^3}{3} + 2(-1)^2 + 2(-1) \right) \\ &= (18 + 18 + 6) - \left( -\frac{2}{3} + 2 - 2 \right) \\ &= 42 - \left( -\frac{2}{3} \right) \\ &= \frac{128}{3}. \end{aligned} \end{equation*}
    Therefore,
    🔗
    \begin{equation*} \displaystyle \int_{-1}^{3} 2(x+1)^2\,dx = \frac{128}{3}. \end{equation*}

    Example 4.7.12.

    Use a definite integral to find the area of the region that lies under the curve \(y = 12 - 4x^2\) and above the \(x\)-axis.
    🔗
    Solution.
    First determine where the curve intersects the \(x\)-axis by solving:
    🔗
    \begin{equation*} 12 - 4x^2 = 0. \end{equation*}
    \begin{equation*} x^2 = 3 \quad \Rightarrow \quad x = \pm \sqrt{3}. \end{equation*}
    The curve is above the \(x\)-axis on the interval \((-\sqrt{3}, \sqrt{3})\text{,}\) so the area is given by:
    🔗
    \begin{equation*} \displaystyle \int_{-\sqrt{3}}^{\sqrt{3}} (12 - 4x^2)\,dx. \end{equation*}
    Evaluate the integral and simplify:
    🔗
    \begin{equation*} \begin{aligned} & \displaystyle \int_{-\sqrt{3}}^{\sqrt{3}} (12 - 4x^2)\,dx \\ &= \left[ 12x - \frac{4x^3}{3} \right]_{-\sqrt{3}}^{\sqrt{3}} \\ &= \left( 12\sqrt{3} - \frac{4(\sqrt{3})^3}{3} \right) - \left( -12\sqrt{3} - \frac{4(-\sqrt{3})^3}{3} \right).\\ &= \left( 12\sqrt{3} - \frac{4 \cdot 3\sqrt{3}}{3} \right) - \left( -12\sqrt{3} + \frac{4 \cdot 3\sqrt{3}}{3} \right) \\ &= (12\sqrt{3} - 4\sqrt{3}) - (-12\sqrt{3} + 4\sqrt{3}) \\ &= 8\sqrt{3} - (-8\sqrt{3}) \\ &= 16\sqrt{3}. \end{aligned} \end{equation*}
    Therefore, the area of the region is \(16\sqrt{3}\text{.}\)

    Example 4.7.13.

    Evaluate the definite integral:
    🔗
    \begin{equation*} \displaystyle \int_{-2}^{1} |x+1|\,dx \end{equation*}
    Solution.
    We saw in a previous example 4.7.10 that this can also be solved by using a geometric approach, but here we will evaluate the integral using the definition of the absolute value function and the Fundamental Theorem of Calculus. Of course if such a problem appears on an exam and it does not specify a method, you can choose either approach.
    🔗
    First determine where the expression inside the absolute value is zero:
    🔗
    \begin{equation*} x+1=0 \quad \Rightarrow \quad x=-1. \end{equation*}
    So we write \(|x+1|\) as a piecewise function:
    🔗
    \begin{equation*} |x+1|= \begin{cases} -(x+1), & x < -1, \\ x+1, & x \ge -1. \end{cases} \end{equation*}
    Split the integral at \(x=-1\text{:}\)
    🔗
    \begin{equation*} \displaystyle \int_{-2}^{1} |x+1|\,dx = \displaystyle \int_{-2}^{-1} -(x+1)\,dx + \displaystyle \int_{-1}^{1} (x+1)\,dx. \end{equation*}
    Evaluate each integral:
    🔗
    \begin{equation*} \begin{aligned} \displaystyle \int_{-2}^{-1} -(x+1)\,dx &= \left[-\left(\frac{x^2}{2}+x\right)\right]_{-2}^{-1}, \\ \displaystyle \int_{-1}^{1} (x+1)\,dx &= \left[\frac{x^2}{2}+x\right]_{-1}^{1}. \end{aligned} \end{equation*}
    Compute the values:
    🔗
    \begin{equation*} \begin{aligned} \displaystyle \int_{-2}^{-1} -(x+1)\,dx &= -\left[\left(\frac{(-1)^2}{2}+(-1)\right) - \left(\frac{(-2)^2}{2}+(-2)\right)\right] \\ &= -\left[\left(\frac{1}{2}-1\right) - (2-2)\right] = -\left(-\frac{1}{2}\right) = \frac{1}{2},\\ \displaystyle \int_{-1}^{1} (x+1)\,dx &= \left[\left(\frac{1}{2}+1\right) - \left(\frac{1}{2}-1\right)\right] \\ &= \frac{3}{2} - \left(-\frac{1}{2}\right) = 2. \end{aligned} \end{equation*}
    Add the results:
    🔗
    \begin{equation*} \displaystyle \int_{-2}^{1} |x+1|\,dx = \frac{1}{2} + 2 = \frac{5}{2}. \end{equation*}

    Example 4.7.14.

    Evaluate the integral \(\displaystyle \int_{0}^{\pi/12} \sec(3x)\tan(3x) \,dx\)
    🔗
    Solution.
    Thinking back to our antiderivative rules 4.1.6, we know that the derivative of \(\sec(3x)\) is \(3\sec(3x)\tan(3x)\text{.}\) So we can use the Fundamental Theorem of Calculus to evaluate the integral:
    🔗

    Example 4.7.17.

    A fish population in a lake is \(2500\) at time \(t=0\text{.}\) The population is changing at a rate of
    🔗
    \begin{equation*} r(t)=300e^{-t/5} \end{equation*}
    fish per month, where \(t\) is measured in months. What is the fish population after \(6\) months?
    🔗
    Solution.
    Since \(r(t)\) is the rate of change of the population, the total change in population from \(t=0\) to \(t=6\) is(according to the Net Change Theorem):
    🔗
    \begin{equation*} P(6)-P(0)= \displaystyle \int_0^6 r(t)\,dt = \displaystyle \int_0^6 300e^{-t/5}\,dt. \end{equation*}
    Now evaluate the integral (by finding the antiderivative).
    🔗
    \begin{equation*} \displaystyle \int 300e^{-t/5}\,dt = -1500e^{-t/5}+C. \end{equation*}
    Therefore the change in population from \(t=0\) to \(t=6\) is,
    🔗
    \begin{equation*} \begin{aligned} P(6)-P(0) \amp =\displaystyle \int_0^6 300e^{-t/5}\,dt\\ \amp = \left.-1500e^{-t/5}\right|_0^6\\ \amp = -1500e^{-6/5}+1500 \end{aligned} \end{equation*}
    Thus, the fish population after \(6\) months is the initial population plus the change in population:
    🔗
    \begin{equation*} \begin{aligned} P(6) \amp =P(0)+\left(-1500e^{-6/5}+1500\right)\\ \amp =2500+\left(-1500e^{-6/5}+1500\right)\\ \amp =4000-1500e^{-6/5} \end{aligned} \end{equation*}
    Using a calculator to approximate,
    🔗
    \begin{equation*} P(6)\approx 4000-1500(0.3010)\approx 3548.2. \end{equation*}
    So after \(6\) months, the fish population is about \(3548\text{.}\) If you did not have a calculator (like on an exam), you should leave the answer in the form \(4000-1500e^{-6/5}\text{.}\)

    Subsection Section 4.6 Substitution Rule for Integration

    Example 4.7.18.

    Evaluate \(\displaystyle \int x\sqrt{3x+4}\,dx\text{.}\)
    🔗
    Solution.
    Let \(u=3x+4\text{,}\) so \(du=3\,dx\) and \(dx=\tfrac13\,du\text{.}\) We also solve for \(x\text{:}\) \(u=3x+4\) gives \(x=\tfrac13u-\tfrac43\text{.}\)
    🔗
    \begin{equation*} \begin{array}{rcl} \displaystyle \int x\sqrt{3x+4}\,dx &=& \displaystyle \int \left(\tfrac13u-\tfrac43\right)\sqrt{u}\cdot \tfrac13\,du \\[0.9em] &=& \displaystyle \int \left(\tfrac19u^{3/2}-\tfrac49u^{1/2}\right)\,du \\[0.9em] &=& \displaystyle \tfrac19\cdot \tfrac{2}{5}u^{5/2}-\tfrac49\cdot \tfrac{2}{3}u^{3/2}+C \\[0.9em] &=& \displaystyle \tfrac{2}{45}(3x+4)^{5/2}-\tfrac{8}{27}(3x+4)^{3/2}+C. \end{array} \end{equation*}
    🔗
    🔗

    Example 4.7.19.

    Evaluate \(\displaystyle \int \frac{\sin(x)}{(1+\cos(x))^2}\,dx\text{.}\)
    🔗
    Solution.
    Let \(u=1+\cos(x)\text{.}\) Then \(du=-\sin(x)\,dx\text{,}\) so \(\sin(x)\,dx=-du\text{.}\)
    🔗
    \begin{equation*} \begin{array}{rcl} \displaystyle \int \frac{\sin(x)}{(1+\cos(x))^2}\,dx &=& \displaystyle -\int \frac{1}{u^2}\,du \\[0.9em] &=& \displaystyle -\left(\frac{u^{-1}}{-1}\right)+C \ =\ \frac{1}{u}+C \\[0.9em] &=& \displaystyle \frac{1}{1+\cos(x)}+C. \end{array} \end{equation*}

    Example 4.7.20.

    Evaluate \(\displaystyle \int \sec^2(x)\tan(x)\,dx\) in two ways, and explain why the answers agree.
    🔗
    Solution.
    Method 1: Let \(u=\tan(x)\text{.}\) Then \(du=\sec^2(x)\,dx\text{.}\)
    🔗
    \begin{equation*} \begin{array}{rcl} \displaystyle \int \sec^2(x)\tan(x)\,dx &=& \displaystyle \int u\,du \ =\ \tfrac12 u^2 + C \ =\ \tfrac12\tan^2(x)+C. \end{array} \end{equation*}
    Method 2: Write the integrand as \(\sec(x)\cdot (\tan(x)\sec(x))\) and let \(z=\sec(x)\text{.}\) Then \(dz=\tan(x)\sec(x)\,dx\text{.}\)
    🔗
    \begin{equation*} \begin{array}{rcl} \displaystyle \int \sec^2(x)\tan(x)\,dx &=& \displaystyle \int z\,dz \ =\ \tfrac12 z^2 + C \ =\ \tfrac12\sec^2(x)+C. \end{array} \end{equation*}
    These differ by a constant because \(\sec^2(x)=\tan^2(x)+1\text{.}\) So \(\tfrac12\sec^2(x)=\tfrac12\tan^2(x)+\tfrac12\text{,}\) meaning the two antiderivative families are the same.

    Example 4.7.21.

    Consider the function \(f(x)=\dfrac{1}{x([\ln(x)]^2+1)}\)
    🔗
    1. Find an antiderivative of \(f(x)\text{.}\)
      🔗
    2. Evaluate \(\displaystyle \int_1^e f(x)\,dx\text{.}\)

    🔗
