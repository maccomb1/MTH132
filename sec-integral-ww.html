    Subsection Section 4.1 Antiderivatives

    Example 4.7.1.

    Find the most general antiderivative of
    \begin{equation*} f(x) = 4x^2 - \frac{1}{x^3} + \sin(2x). \end{equation*}
    Check your answer by differentiating.
    🔗
    Solution.
    First rewrite the function using exponents:
    🔗
    \begin{equation*} f(x) = 4x^2 - x^{-3} + \sin(2x). \end{equation*}
    Now use the rules for antiderivatives 4.1.6 of powers and trigonometric functions, along with linearity, to build an antiderivative term-by-term:
    🔗
    \begin{equation*} F(x) = 4\left(\frac{1}{3}x^3\right) + \frac{1}{2}x^{-2} - \frac{1}{2}\cos(2x) + C \end{equation*}
    We can check our answer by differentiating:
    🔗
    \begin{equation*} \begin{aligned} \amp \; \frac{d}{dx}\left(\frac{4x^3}{3} + \frac{1}{2}x^{-2} - \frac{1}{2}\cos(2x) + C\right)\\[6pt] \amp= \frac{4}{3}\cdot 3x^2 + \frac{1}{2}(-2)x^{-3} - \frac{1}{2}(-\sin(2x))\cdot 2 \\[6pt] \amp= 4x^2 - x^{-3} + \sin(2x) \\[6pt] \amp= 4x^2 - \frac{1}{x^3} + \sin(2x) \end{aligned} \end{equation*}
    Since differentiating recovers the original function, the result is confirmed as the most general antiderivative.
    🔗
    🔗
    🔗

    Example 4.7.2.

    Find the antiderivative \(F(x)\) of
    \begin{equation*} f(x) = \frac{2}{x^4} - \frac{9}{2x^2} \end{equation*}
    which satisfies \(F(-1)=10\text{.}\)
    🔗
    Solution.
    First rewrite the function using exponents:
    🔗
    \begin{equation*} f(x) = 2x^{-4} - \frac{9}{2}x^{-2}. \end{equation*}
    Now use the rules for antiderivatives 4.1.6 of powers, along with linearity, to build the most general antiderivative term-by-term:
    🔗
    \begin{equation*} F(x) = 2\left(\frac{x^{-3}}{-3}\right) - \frac{9}{2}\left(\frac{x^{-1}}{-1}\right) + C \end{equation*}
    Simplifying gives
    🔗
    \begin{equation*} F(x) = -\frac{2}{3}x^{-3} + \frac{9}{2}x^{-1} + C. \end{equation*}
    Since \(F(-1)=10\text{,}\) substitute \(x=-1\) to find \(C\text{:}\)
    🔗
    \begin{equation*} \begin{aligned} 10 \amp= F(-1) \\[4pt] \amp= -\frac{2}{3}(-1)^{-3} + \frac{9}{2}(-1)^{-1} + C \\[4pt] \amp= \frac{2}{3} - \frac{9}{2} + C. \end{aligned} \end{equation*}
    Solving for \(C\text{,}\) we get
    🔗
    \begin{equation*} \begin{aligned} C \amp= 10 - \frac{2}{3} + \frac{9}{2} \\[4pt] \amp= \frac{60}{6} - \frac{4}{6} + \frac{27}{6} \\[4pt] \amp= \frac{83}{6}. \end{aligned} \end{equation*}
    Therefore, the antiderivative is
    🔗
    \begin{equation*} F(x) = -\frac{2}{3}x^{-3} + \frac{9}{2}x^{-1} + \frac{83}{6}. \end{equation*}
    We can check our answer by differentiating and verifying the given value:
    🔗
    \begin{equation*} \begin{aligned} F'(x) \amp= \frac{d}{dx}\left(-\frac{2}{3}x^{-3} + \frac{9}{2}x^{-1} + \frac{83}{6}\right) \\[4pt] \amp= -\frac{2}{3}(-3)x^{-4} + \frac{9}{2}(-1)x^{-2} \\[4pt] \amp= 2x^{-4} - \frac{9}{2}x^{-2} \\[4pt] \amp= \frac{2}{x^4} - \frac{9}{2x^2} \end{aligned} \end{equation*}
    \begin{equation*} \begin{aligned} F(-1) \amp= -\frac{2}{3}(-1)^{-3} + \frac{9}{2}(-1)^{-1} + \frac{83}{6} \\[4pt] \amp= \frac{2}{3} - \frac{9}{2} + \frac{83}{6} \\[4pt] \amp= 10. \end{aligned} \end{equation*}
    Since \(F'(x)=f(x)\) and \(F(-1)=10\text{,}\) the result is confirmed.
    🔗
    🔗
    🔗

    Example 4.7.3.

    Find the most general antiderivative of
    \begin{equation*} f(x) = \frac{3\sqrt{x}-2x^3}{x}. \end{equation*}
    Check your answer by differentiating.
    🔗
    Solution.
    First simplify the expression and rewrite using exponents:
    🔗
    \begin{equation*} f(x) = \frac{3\sqrt{x}}{x} - \frac{2x^3}{x} = 3x^{-1/2} - 2x^2. \end{equation*}
    Now use the rules for antiderivatives 4.1.6 of powers, along with linearity, to build an antiderivative term-by-term:
    🔗
    \begin{equation*} F(x) = 3\left(\frac{x^{1/2}}{1/2}\right) - 2\left(\frac{x^3}{3}\right) + C \end{equation*}
    Simplifying gives
    🔗
    \begin{equation*} F(x) = 6x^{1/2} - \frac{2}{3}x^3 + C. \end{equation*}
    We can check our answer by differentiating:
    🔗
    \begin{equation*} \begin{aligned} \amp \; \frac{d}{dx}\left(6x^{1/2} - \frac{2}{3}x^3 + C\right) \\[6pt] \amp= 6\left(\frac{1}{2}x^{-1/2}\right) - \frac{2}{3}(3x^2) \\[6pt] \amp= 3x^{-1/2} - 2x^2. \end{aligned} \end{equation*}
    Since differentiating recovers the original function, the result is confirmed as the most general antiderivative.
    🔗
    🔗
    🔗

    Example 4.7.4.

    An object moves along a coordinate line with velocity
    \begin{equation*} v(t) = 6t^2 - 7 \end{equation*}
    (in units per second). Its initial position is 5 units to the left of the origin. Find the position of the object after 3 seconds.
    🔗
    Solution.
    Let \(s(t)\) be the position of the object at time \(t\text{.}\) Since velocity is the derivative of position, we have
    🔗
    \begin{equation*} s'(t) = v(t) = 6t^2 - 7. \end{equation*}
    Thus \(s(t)\) is an antiderivative of \(6t^2 - 7\text{.}\) Using the rules for antiderivatives 4.1.6, we obtain the most general form:
    🔗
    \begin{equation*} s(t) = 2t^3 - 7t + C. \end{equation*}
    We are given that the initial position is 5 units to the left of the origin, so \(s(0) = -5\text{.}\) Substituting:
    🔗
    \begin{equation*} \begin{aligned} s(0) -5 \amp= 2(0)^3 - 7(0) + C \\[4pt] -5 \amp= C. \end{aligned} \end{equation*}
    Therefore \(C = -5\text{,}\) and the position function is
    🔗
    \begin{equation*} s(t) = 2t^3 - 7t - 5. \end{equation*}
    To find the position after 3 seconds, evaluate:
    🔗
    \begin{equation*} \begin{aligned} s(3) \amp= 2(3)^3 - 7(3) - 5 \\[4pt] \amp= 54 - 21 - 5 \\[4pt] \amp= 28. \end{aligned} \end{equation*}
    Since the position is positive, the object is 28 units to the right of the origin after 3 seconds.
    🔗
    We can check our work by differentiating:
    🔗
    \begin{equation*} \begin{aligned} s'(t) \amp= \frac{d}{dt}\left(2t^3 - 7t - 5\right) \\[4pt] \amp= 6t^2 - 7 \\[4pt] \amp= v(t). \end{aligned} \end{equation*}
    Since differentiating recovers the given velocity, the result is confirmed.
    🔗

    Example 4.7.5.

    Solve the initial value problem:
    \begin{equation*} \frac{dy}{dt} = \frac{2}{t^2+1} - \frac{9}{2t}, \quad y(-1)=0. \end{equation*}
    🔗
    Solution.
    Our goal is to find a function \(y(t)\) such that \(y' = \frac{2}{t^2+1} - \frac{9}{2t}\) and \(y(-1)=0\text{.}\)
    🔗
    First, we find the most general antiderivative of the right-hand side by using the rules for antiderivatives 4.1.6.
    🔗
    \begin{equation*} y(t) = 2\arctan(t) - \frac{9}{2}\ln|t| + C. \end{equation*}
    Now we use the initial condition \(y(-1)=0\) to solve for \(C\text{:}\)
    🔗
    \begin{equation*} \begin{aligned} 0 \amp= y(-1) \\[4pt] 0\amp= 2\arctan(-1) - \frac{9}{2}\ln|-1| + C \\[4pt] 0\amp= 2\left(-\frac{\pi}{4}\right) - 0 + C \\[4pt] 0\amp= -\frac{\pi}{2} + C \\[4pt] \frac{\pi}{2} \amp = C \end{aligned} \end{equation*}
    Therefore, the solution to the initial value problem is
    🔗
    \begin{equation*} y(t) = 2\arctan(t) - \frac{9}{2}\ln|t| + \frac{\pi}{2}. \end{equation*}

    Example 4.7.6.

    A small population is decreasing over time. Let \(P(t)\) be the population after \(t\) years. Suppose the rate of change is modeled by
    \begin{equation*} P'(t) = -15e^{-0.2t}. \end{equation*}
    🔗
    1. Write a general formula for \(P(t)\) assuming an unknown initial population.
      🔗
      🔗
    2. If the initial population is \(500\text{,}\) find the specific formula for \(P(t)\text{.}\)
      🔗
      🔗
    3. According to the model, what will the population be after 3 years?
      🔗
      🔗
    Solution.
    (a) Since \(P'(t)\) is given, the function \(P(t)\) is an antiderivative of \(-15e^{-0.2t}\text{.}\)
    🔗
    Using the rules for antiderivatives 4.1.6, we obtain:
    🔗
    \begin{equation*} P(t) = -15\left(\frac{1}{-0.2}e^{-0.2t}\right) + C. \end{equation*}
    Simplifying gives
    🔗
    \begin{equation*} P(t) = 75e^{-0.2t} + C. \end{equation*}
    This is the general formula.
    🔗
    (b) Now use the initial condition \(P(0)=500\text{:}\)
    🔗
    \begin{equation*} \begin{aligned} 500 \amp= P(0) \\[4pt] 500 \amp= 75e^{0} + C \\[4pt] 500 \amp= 75 + C\\[4pt] 425 \amp= C \end{aligned} \end{equation*}
    Therefore, the specific formula is
    🔗
    \begin{equation*} P(t) = 75e^{-0.2t} + 425. \end{equation*}
    (c) Now evaluate at \(t=3\text{:}\)
    🔗
    \begin{equation*} P(3) = 75e^{-0.6} + 425 \end{equation*}
    With access to a calculator (if one is permitted), we can find a decimal approximation to be about \(466\text{.}\)

    Subsection Section 4.6 Substitution Rule for Integration

    Example 4.7.7.

    Evaluate \(\displaystyle \int x\sqrt{3x+4}\,dx\text{.}\)
    🔗
    Solution.
    Let \(u=3x+4\text{,}\) so \(du=3\,dx\) and \(dx=\tfrac13\,du\text{.}\) We also solve for \(x\text{:}\) \(u=3x+4\) gives \(x=\tfrac13u-\tfrac43\text{.}\)
    🔗
    \begin{equation*} \begin{array}{rcl} \displaystyle \int x\sqrt{3x+4}\,dx &=& \displaystyle \int \left(\tfrac13u-\tfrac43\right)\sqrt{u}\cdot \tfrac13\,du \\[0.9em] &=& \displaystyle \int \left(\tfrac19u^{3/2}-\tfrac49u^{1/2}\right)\,du \\[0.9em] &=& \displaystyle \tfrac19\cdot \tfrac{2}{5}u^{5/2}-\tfrac49\cdot \tfrac{2}{3}u^{3/2}+C \\[0.9em] &=& \displaystyle \tfrac{2}{45}(3x+4)^{5/2}-\tfrac{8}{27}(3x+4)^{3/2}+C. \end{array} \end{equation*}
    🔗
    🔗

    Example 4.7.8.

    Evaluate \(\displaystyle \int \frac{\sin(x)}{(1+\cos(x))^2}\,dx\text{.}\)
    🔗
    Solution.
    Let \(u=1+\cos(x)\text{.}\) Then \(du=-\sin(x)\,dx\text{,}\) so \(\sin(x)\,dx=-du\text{.}\)
    🔗
    \begin{equation*} \begin{array}{rcl} \displaystyle \int \frac{\sin(x)}{(1+\cos(x))^2}\,dx &=& \displaystyle -\int \frac{1}{u^2}\,du \\[0.9em] &=& \displaystyle -\left(\frac{u^{-1}}{-1}\right)+C \ =\ \frac{1}{u}+C \\[0.9em] &=& \displaystyle \frac{1}{1+\cos(x)}+C. \end{array} \end{equation*}
    🔗
    🔗

    Example 4.7.9.

    Evaluate \(\displaystyle \int \sec^2(x)\tan(x)\,dx\) in two ways, and explain why the answers agree.
    🔗
    Solution.
    Method 1: Let \(u=\tan(x)\text{.}\) Then \(du=\sec^2(x)\,dx\text{.}\)
    🔗
    \begin{equation*} \begin{array}{rcl} \displaystyle \int \sec^2(x)\tan(x)\,dx &=& \displaystyle \int u\,du \ =\ \tfrac12 u^2 + C \ =\ \tfrac12\tan^2(x)+C. \end{array} \end{equation*}
    Method 2: Write the integrand as \(\sec(x)\cdot (\tan(x)\sec(x))\) and let \(z=\sec(x)\text{.}\) Then \(dz=\tan(x)\sec(x)\,dx\text{.}\)
    🔗
    \begin{equation*} \begin{array}{rcl} \displaystyle \int \sec^2(x)\tan(x)\,dx &=& \displaystyle \int z\,dz \ =\ \tfrac12 z^2 + C \ =\ \tfrac12\sec^2(x)+C. \end{array} \end{equation*}
    These differ by a constant because \(\sec^2(x)=\tan^2(x)+1\text{.}\) So \(\tfrac12\sec^2(x)=\tfrac12\tan^2(x)+\tfrac12\text{,}\) meaning the two antiderivative families are the same.
